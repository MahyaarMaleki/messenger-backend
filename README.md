# Messenger Project - Backend API

This repository contains the backend service for a Messenger application. It is built using Go and follows the Standard Go Project Layout + clean architecture.

## 🛠 Tech Stack

* **Language:** Go (Golang)
* **Database:** PostgreSQL
* **Routing:** [Chi](https://go-chi.io/#/) (Lightweight, idiomatic router)
* **Database Access:** [SQLC](https://sqlc.dev/) (Type-safe code generation from raw SQL)
* **Migrations:** [goose](https://pressly.github.io/goose/)
* **Real-time:** WebSockets

## 📂 Project Structure

This project follows the **Standard Go Project Layout**:

* `cmd/api`: Entry point for the REST API server.
* `internal/api`: HTTP handlers (including business logic) and routing logic.
* `internal/service`: Business logic and use cases.
* `internal/db`: Data access layer (Auto-generated by SQLC).
* `database/`: SQL migrations and queries.
